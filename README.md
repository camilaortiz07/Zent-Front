💸 Control de Gastos Hormiga - Front End 💸
¡Esos pequeños gastos son los que más pesan al final del mes! Esta es una aplicación diseñada para visualizar y registrar de manera rápida todos esos consumos cotidianos que suelen pasar desapercibidos, como el café de la mañana, snacks o suscripciones olvidadas.

El objetivo principal es ayudar al usuario a tomar las riendas de su salud financiera mediante la identificación de fugas de dinero.

🚀 Características principales
Registro rápido: Interfaz simplificada para anotar gastos en segundos.

Categorización dinámica: Clasificación por tipo de gasto (alimentación, transporte, ocio, etc.).

Visualización de impacto: Gráficos o resúmenes que muestran cuánto suman esos pequeños montos semanal o mensualmente.

Interfaz Responsiva: Diseñada para ser utilizada cómodamente tanto en escritorio como en dispositivos móviles.

🛠️ Tecnologías utilizadas
Lenguaje: Java

Gestión de Versiones: Git y GitHub.
